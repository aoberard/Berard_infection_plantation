This compendium contains the raw data and scripts required to reproduce the analyses presented in the associated paper.



\# Reproductibility
R version: 4.6.0
Package management: renv

\#Running the analyses
The main script, make.R, launches the analysis scripts located in the analyses/ folder in the appropriate order.
To reproduce the analyses, open the project in RStudio and run make.R.
The use of a high-performance computing cluster is strongly recommended for the HMSC analyses, as these analyses can be computationally intensive and may require substantial running time with the current model parameters.



\# Data
All data files are stored in the data/ folder.

\## Raw data (data/raw-data/)
The raw-data/ folder contains the following input files:

\## Field data and metadata
dissected\_indiv.csv: Individual-level data for dissected Apodemus sylvaticus specimens screened for infectious agents.
apodemus\_number.csv: Total number of Apodemus sylvaticus sampled per site-session, including individuals that were not dissected.
lines\_variability.csv: Site-session metadata.
agents\_traits: Trait and taxonomic information for the infectious agents included in the HMSC analyses.

\## Metabarcoding data
Abundance and taxonomic assignment tables for the three metabarcoding approaches (gltA, rpoB and 16S):
2026.03.10-gltA.taxonomy.final.blastn.txt
2026.03.20-gltA.abundance.final.txt
2023.03.23-rpoB.taxonomy.final.blastn.clean.txt
2026.03.20-rpoB.abundance.final.txt
2026.03.24-16S.abundance.final.txt

\## qPCR data
20260602\_data\_qPCR\_lepto\_BePrep.xlsx: lipL32 qPCR results used for Leptospira screening.



\# Derived data (data/derived-data/)
The derived-data/ folder is automatically generated by the analysis scripts from the raw data. It contains intermediate and final datasets used in subsequent analyses.

\# Outputs
Analysis outputs are organized into two folders:
derived-data/: intermediate and processed datasets.
figures/: figures generated by the analysis scripts.
